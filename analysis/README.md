# `analysis/` — *Python + Big Data*

The last project lives here. Three things, all committed:

| What | File |
|---|---|
| Your script, in full — you should be able to explain any line of it | `analyze.py` |
| Your chart | `chart.png` |
| The dataset, the inspection, the three questions, the chart's claim, and what an AI got wrong | `FINDINGS.md` |

`FINDINGS.md` goes in this order, and **step 5 is a scored criterion, not a
bonus round**:

1. **The dataset** — what it is, where it came from, how many rows.
2. **What inspection revealed** — shape, types, missing values, and for each
   problem you found, how it would have corrupted the analysis if you had not
   looked.
3. **Your three questions** — the prediction you wrote down *before* running it,
   then what the data actually said, **with the group count behind every
   number**.
4. **The chart** — `chart.png`, and the one sentence it argues.
5. **What an AI got wrong about this data** — and how you caught it.

A dataset with nothing wrong in it, and an AI that made no mistakes about it,
almost always means the inspection in step 2 was too shallow to find anything.
